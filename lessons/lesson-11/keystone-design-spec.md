# 第 11 课关键页设计规格

依据 [正式课堂 PPT 设计准则](../ppt-design-criteria.md) v1.2.0。屏显文案、讲述、互动、时间和来源以 [slides.md](./slides.md) v0.2.3 为唯一现行母稿。

## 一、关键页集合

关键页：`P01 / P04 / P06 / P07 / P09 / P10 / P11 / P12 / P13 / P14 / P17 / P18 / P19`。

| 风险类型 | 页面 | 选择理由 |
| --- | --- | --- |
| 开场与收束 | P01、P19 | 开场要建立“跑通一次不等于循环成立”；收束必须把循环骨架交给第 12 课个人工作流设计 |
| 核心模型 | P04、P06、P07 | 五步、固定指标与停止触发器是受限循环的主要结构，易被误读为无界试错 |
| 教学反例与演示 | P09、P10 | 指标篡改反例和贯穿案例必须显式标注课程教学示意，且呈现可追踪工件 |
| 失败保留 | P11 | 七字段记录和数账等式直接支撑第 13 课验证门，不能缩成口号 |
| 外部案例边界 | P12-P14 | AutoResearch / AI Scientist 只能作分析对象；来源、范围、人工判断与不外推清单必须同框 |
| 长停留与互查 | P17、P18 | 学生应不依赖教师重复说明完成检查、失败记录与同伴质询 |

## 二、关键页契约

### P01｜跑通一次不等于受限循环成立

- **页面任务与主结论**：把第 10 课的单次受限执行推进到可重复、可评价、可回退的实验追踪。
- **主视觉锚点及来源**：`一次执行 → 受限循环 → 工作流设计` 单线；课程研究链路示意。
- **与相邻页的叙事关系**：封面提出差距；P02 展开已有工件与缺口。
- **最小成立内容**：课名、核心判断、阶段七定位、第 12 课去向。

### P04｜五步必须逐步留下可审查工件

- **页面任务与主结论**：循环不是重复运行，而是“假设→运行→度量→评价→回写/回退”五步均留下工件。
- **主视觉锚点及来源**：五节点主链及从末端回到假设的回退箭头；课程方法重绘。
- **与相邻页的叙事关系**：P03 定义产出；P04 给骨架；P05 检查适用边界。
- **最小成立内容**：五步、每步工件、三项预先承诺。

### P06｜指标定义文件在循环期间不可被工作流修改

- **页面任务与主结论**：固定指标指计算口径与版本固定，不只是指标名称固定。
- **主视觉锚点及来源**：一份教学指标定义文件，旁列三种协议漂移；课程教学工件。
- **与相邻页的叙事关系**：P05 判断是否适用；P06 固定评价；P07 固定资源与停止。
- **最小成立内容**：口径/分母分子/缺失处理/标注协议、三种漂移、运行前后检查。

### P07｜预算与停止条件把循环锁在预先承诺内

- **页面任务与主结论**：预算是硬上限，停止条件必须区分正常、协议性与禁止三类。
- **主视觉锚点及来源**：一条预算上限 + 三岔停止触发器；课程方法重绘。
- **与相邻页的叙事关系**：承接固定指标；P08 决定触发后回退到哪里。
- **最小成立内容**：四种预算、三类触发器、禁止结果导向停止。

### P09｜结果不利后换指标就是评价协议漂移

- **页面任务与主结论**：学生从日志中识别指标篡改，并知道正确动作是 Discard + 回退。
- **主视觉锚点及来源**：虚构循环日志的 before/after 对照；画面明确“课程教学反例”。
- **与相邻页的叙事关系**：P08 定义回退；P09 用反例触发；P10 给完整受限版本。
- **最小成立内容**：换指标日志、问题定位、固定指标改写。

### P10｜贯穿案例把四约束落到五步工件

- **页面任务与主结论**：把阅读卡摘要这一可重复动作改写为具体受限循环。
- **主视觉锚点及来源**：上方四约束、下方五步伪代码，二者共享变量；课程教学案例，虚构参数。
- **与相邻页的叙事关系**：P09 从错误切入；P10 给正确 trace；P11 要求失败同样入账。
- **最小成立内容**：四约束数字、五步骨架、人工审核点、教学示意标记。

### P11｜失败记录必须能与总迭代数对账

- **页面任务与主结论**：Discard 不是删除，失败要用七字段进入可审计记录。
- **主视觉锚点及来源**：七字段记录表 + `失败 + 成功 = 总迭代` 等式；课程工件示意。
- **与相邻页的叙事关系**：P10 完成循环；P11补齐失败追踪；P12转向外部案例分析。
- **最小成立内容**：七字段、Discard 但记录保留、数账等式。

### P12｜AutoResearch 与 AI Scientist 是两个分析对象

- **页面任务与主结论**：区分最小工程循环与端到端边界案例，不把任何一个当作通用能力证明。
- **主视觉锚点及来源**：左右对照；AutoResearch commit `228791f` 与 Lu et al. 2026。
- **与相邻页的叙事关系**：P11完成课程骨架；P12引入对象；P13进入八维拆解。
- **最小成立内容**：两对象、两角色、“分析对象≠外推依据”、固定版本/论文身份。

### P13｜八维拆解的重点是仍需人工判断

- **页面任务与主结论**：逐维辨认系统处理与人工判断的分界。
- **主视觉锚点及来源**：八维表，右侧“仍需人工判断”形成主阅读列；课程框架 + Lu et al. 2026。
- **与相邻页的叙事关系**：承接P12对象；P13拆解；P14归纳不可越过的结论边界。
- **最小成立内容**：八维、系统已处理、仍需人工、自动评审不等于同行共识。

### P14｜端到端自动化和自动评审都不能直接外推

- **页面任务与主结论**：把两个边界判断转成五条可执行的不外推检查。
- **主视觉锚点及来源**：两个大号不等式 + 五条否定清单；Nature 论文边界与课程证据标准。
- **与相邻页的叙事关系**：P13逐维分析；P14收束边界；P15回到自己的循环做比较。
- **最小成立内容**：两个不等式、五条不得改写、改写原则。

### P17｜学生在停留页上补全并检查失败记录

- **页面任务与主结论**：学生可独立完成循环说明、失败记录和不外推自查。
- **主视觉锚点及来源**：左侧七项检查，右侧七字段失败记录；课程教学样例，虚构 ID/commit/rubric。
- **与相邻页的叙事关系**：P16发出任务；P17支持十分钟实践；P18转入同伴质询。
- **最小成立内容**：四约束、三类停止、五步、≥3审核点、失败七字段、八维≥4、数账等式。

### P18｜同伴只检查约束与边界，不替作者决定

- **页面任务与主结论**：把互查限定为五个可回答的问题，作者保留决定权。
- **主视觉锚点及来源**：作者/同伴责任分工 + 五问；课堂活动设计。
- **与相邻页的叙事关系**：P17形成个人工件；P18做外部检查；P19把卡点带入下一课。
- **最小成立内容**：五问、只提问题、不共同提交、10分钟。

### P19｜第 12 课把循环骨架重新组合为个人工作流

- **页面任务与主结论**：回答开场问题，把受限循环变成下一课的工作流设计输入。
- **主视觉锚点及来源**：第10–13课路线，突出第11→12课跃迁；课程路线示意。
- **与相邻页的叙事关系**：承接P18反馈；回扣P01；落到第12课任务契约、Context、Memory、权限、Evals与审核点。
- **最小成立内容**：退出卡四问、第12课动作、本课无正式提交、第13课验证门去向。

## 三、模板例外与制作约束

- 以 `lessons/lesson-07/slides.pptx` 为直接视觉基线，克隆源页并编辑继承对象，保留 master → layout → slide 层级。
- P01 沿用交大封面；标准内容页保留交大红标题带、校徽、页脚与页码。
- P04、P07 的连接线先于节点创建；静态状态必须完整可读，不依赖 Morph。
- P09、P10、P17 的虚构教学工件在画面与 notes 同时标记，不伪装成真实日志或实证结果。
- P12-P14 不使用生成式伪截图；以可编辑结构和准确来源身份呈现，外部事实写入 notes `[Sources]`。
- P13、P17 为精读工件页，课堂阅读文字不低于 18 pt；P17 为长停留页，优先任务、检查和可核验产出。
