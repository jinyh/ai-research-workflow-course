# 实验规格：合成记录遗漏率复算

- 假设对应：只验证“固定口径可从原始记录重算”，不检验任何方法优劣。
- 变量：输入记录中的 `condition_present`；输出为遗漏数与遗漏率。
- 步骤：读取配置与合成输入，按布尔字段计数，核对结果与日志。
- 度量标准：`omission_rate = missing / records`。
- 对照：无方法比较；本工件只演示追踪链。
- 随机化与重复：确定性计算，无随机源；等价复现条件为相同输入、配置和 Python 3。
- 停止条件：处理完配置声明的 4 条记录即停止；记录数不符则失败。

边界：这是实际可运行的课程工件，但数据为合成数据，结果不能外推为科研结论。
