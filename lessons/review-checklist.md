# 逐课材料审校检查清单

本清单与 [备课规划.md](./备课规划.md) "六、双引擎备课协作" 的四维审阅（事实准确性、教学节奏、跨文档一致性、可执行性）配合使用。"表述口吻"是补入的第五审阅维。每课材料定稿前，主笔按下列四类逐项自检，审阅者据此复核。

## 一、表述口吻（第五审阅维）

目标：让材料读起来像一位资深研究者在讲课，而不是 AI 生成稿。**注意边界**：课程 handout 本身就高密度使用结构化术语并列、"不能…只能…"限定式和术语表，这是课程固有风格，必须保留。要去除的是以下四类 AI 生成痕迹。

- [ ] **对仗句式去密**：通篇"不是 X，而是 Y"是否页页/段段出现？保留 2-3 处确有张力的点睛句，其余转正面陈述。
- [ ] **meta 自白清除**：备注或正文中是否反复出现"本页只建立张力""本页是为了 X""这里引用它是为了 Y"等设计意图自白？改为教师面对学生的自然过渡语或直接陈述。
- [ ] **机械编号松绑**：备注里"先…再…最后…"是否滥用？保留必要编号，但把整齐的编号叙述改散句。
- [ ] **标题腔降格**：页/节标题是否清一色判断句、读成格言集？约半数改为更具体的指引式，少数保留有力判断句。
- [ ] **否定式指导克制**：视觉/制作指导是否靠"不要…"堆叠？保留功能性 2-3 处，其余转正面表述（如"使用极简封面"代"不使用 Logo 拼贴"）。
- [ ] **讲述与设计说明区分**：教师讲述备注是否写成设计理由（"X 从首课使用，是因为…"）？改为可直接说出口的讲述版本，设计理由并入"来源与事实边界"。

## 二、实质一致性

- [ ] 贯穿案例衔接：演示案例与个人实践题池是否同质？若同一问题同时用于教师演示和学生作业，个人实践会沦为复刻。
- [ ] 跨页案例线索：从"一句 AI 总结"到"可检验问题"等贯穿案例，跨页是否有明确过渡，还是被读成两个不相干例子？
- [ ] 时间表自洽：节奏表页码区间与各页"建议时间"是否一致、有无重叠或遗漏？合计是否覆盖 0-90 分钟。
- [ ] 与 handout/teaching-plan 口径一致：八阶段命名顺序、四门课次（第 6/9/13/16 课）、证据标准（`stable` 需两项独立证据）、OpenCode 角色定位（平台非学习目标）、最小可审计交互两步任务契约文字、评分比例（25/30/25/20）逐项核对。
- [ ] 备用题池与演示主题区分：题池首题是否复用课堂演示的研究问题？

## 三、事实口径

- [ ] 引文核对：Nature/期刊论文的 DOI、卷期、页码、标题与 ref/papers 原件、ref/nature.md、ref/README.md 四层自洽。
- [ ] 内部文档路径：所有 `../course/<file>` 相对链接指向的文件确实存在。
- [ ] 时效与分级：引用 ref/ 中材料时，A 级原件可直接用，B/C 二手整理（如 nature.md）须标注"授课前回源核验"。
- [ ] 不虚构：无虚构文献、数据、实验结果或引文。课堂虚构示例须在页面和讲述中标明"未经核验"。
- [ ] AI 输出不作证据：AI 生成的摘要、推断只在核验后作为线索，不直接写成已证实事实。

## 四、版本与文件

- [ ] 不覆盖原版：重大改写前复制留底（如 `lesson-NN-slides-vX.Y.Z.md`），主文件 front matter 升版本号。
- [ ] 版本号合规：版本号只在 front matter，文件名不带版本号（留底备份文件除外）。
- [ ] 变更记录：front matter `变更记录` 追加本次版本条目，说明改了什么、未动什么。
- [ ] Git diff 干净：只含本任务涉及的文件，无凭据、敏感路径、孤儿文件或无关改动。
- [ ] 同步引用：final/README.md、projects/README.md 在引用了被改文件版本时同步。

## 使用方式

1. 主笔完成初稿后，按四类逐项自检，在 front matter `状态` 字段标注自检结论。
2. 审阅引擎（双引擎中的另一方）据此清单复核，只报告问题或边界清晰的修改建议。
3. 重要来源、时效性信息和 PPT 渲染结果仍由人工最终确认（见备课规划.md）。
