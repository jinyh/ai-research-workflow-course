## P01｜AI 可以参与科研，研究责任仍由人承担

- **论证角色**：建立张力。定全课基调——AI 已能做科研动作，但责任仍归人。
- **主视觉对象**：中心判断句"AI 可以参与科研，研究责任仍由人承担"以大字占画布主体，背景为"问题—证据—实验—结论"弱化链路（矢量线条，非卡片）。
- **叙事轮廓**：极简封面（气氛页），弱化主链作背景。与 P02 投票钩子不同。
- **删除标准**：张力页低密度。删到只剩课程名 + 判断句 + "2 学分｜32 学时｜研究生专业选修课"。不放工具图标、不放四阶段并列卡片。
- **主视觉来源**：概念/气氛页 → 矢量留白 + 弱化链路线条；不使用 imagegen（开场不必生成图）。
- **屏显文案要点**：课程名、判断句、学分学时行。其余入 speaker notes。
- **验收三问预答**：① 删主视觉只剩判断句 → 成立（封面页）。② 与 P02 轮廓不同 → 是。③ 无卡片矩阵 → 是。过。

## P07｜研究判断与工程工作流必须放在一起

- **论证角色**：建立冲突。方法侧研究不成立，工作流侧完整——"可检查 ≠ 已成立"。
- **主视觉对象**：一份标注"虚构教学情境"的研究提交，左方法侧显示 `evidence missing / baseline unclear` 判定失败，右工作流侧显示完整 `Context / Permission / Diff / Log`，中间大号"≠"。占画布 ≥40%。
- **叙事轮廓**：对照（左方法 vs 右工作流，差异点"≠"高亮）。与 P06（概念）、P08（说明）不同。
- **删除标准**：张力页低密度。删当前"方法决定…/工作流决定…"两行卡片的对仗复述，改为研究提交 + ≠冲突 + 一句"可检查 ≠ 已成立"。
- **主视觉来源**：工件/操作页 → 真实研究工件重绘（研究提交卡 + diff/log 片段），虚构标注。不用概念卡片。
- **屏显文案要点**：保留"可检查 ≠ 已成立"结论带；方法侧两行失败标记；工作流侧四字段；≠高亮。
- **验收三问预答**：① 删主视觉只剩≠结论 → 成立。② 与 P06/P08 轮廓不同 → 是。③ 真实工件 ≥40% → 是。过。

## P13｜16 次课围绕同一个项目逐步推进

- **论证角色**：给出路线。所有课堂练习回写同一项目，四门 G1-G4 必须穿过。
- **主视觉对象**：一条有高低起伏的任务路径，五个阶段为路径节点，G1-G4（第 6/9/13/16 课）为必须穿过的门槛标记，第 8/15 课放底部形成性节点带。占画布主体。
- **叙事轮廓**：路线图（横轴时间 + 门槛标记）。与 P12（责任分工）、P14（评分条）不同。
- **删除标准**：说明页中密度。删当前五阶段五段并列文本，改为路径上的节点；每页一个主结论"所有练习回写同一项目"。
- **主视觉来源**：路线/评分页 → 横轴路径 + 门槛标记，不用等宽方块。
- **屏显文案要点**：五阶段作路径节点；G1-G4 门槛；8/15 形成性节点带；一句主结论。
- **验收三问预答**：① 删主视觉只剩路径 → 成立。② 与 P12/P14 轮廓不同 → 是。③ 路径对象 ≥40% → 是。过。

## P21｜八阶段让我们知道当前在修改什么

- **论证角色**：给出骨架。八阶段是定位动作、工件和责任的共同语言，带回退。
- **主视觉对象**：八节点单线总图，节点间保留可回退箭头。占画布主体。本页不解释每条回退路径。
- **叙事轮廓**：主链（准则裁定固定）。与 P20（概念/气氛）、P22（阶段对，须用非主链轮廓以满足轮换）不同。
- **删除标准**：说明页中密度。删当前两行链路文字，改为路径节点；保留一句"无论回退还是迭代，都知道当前在改什么"。
- **主视觉来源**：结构/机制页 → 矢量重绘。节点文字、连线、回路在投影尺寸检查（备课教训 #23）。
- **屏显文案要点**：八节点；回退箭头；一句主结论。
- **验收三问预答**：① 删主视觉只剩单线 → 成立。② 与 P20/P22 轮廓不同 → 是。③ 矢量重绘 ≥40% → 是。过。
- **轮换提示**：P22-P25 须分别采用非主链轮廓（对照/责任分工/阶梯等），否则连续违反"3 页不得 2 页同轮廓"。

## P34｜"完成"之后还要检查 diff 和使用记录

- **论证角色**：展示真实工件。以实际文件变化为准，不只听 Agent 自述——冲突"Agent 自述完成 ≠ 文件实际变化"。
- **主视觉对象**：一段简化 `git diff`（删除行/增加行）+ `ai-usage-log.md` 新记录条，占画布主体。右侧五项勾选缩为极简次元素。
- **叙事轮廓**：工件视图（真实 diff/日志占主体）。与 P33（任务契约）、P35（否定清单）不同。
- **删除标准**：张力页低密度。一个 diff + 一条 log + 一句"以实际文件变化为准，不只看自述"。当前五项勾选清单移入 speaker notes 或缩为右侧极简勾选。
- **主视觉来源**：工件/操作页 → 真实研究工件重绘（git diff + log 片段），不用流程卡片假装展示过操作。
- **屏显文案要点**：diff 主体；log 新记录；一句"以实际文件变化为准"。五项检查入 speaker notes。
- **验收三问预答**：① 删主视觉只剩 diff/log → 成立。② 与 P33/P35 轮廓不同 → 是。③ 真实工件 ≥40% → 是。过。
