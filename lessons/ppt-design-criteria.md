# PPT 反卡片设计准则（草案）

本准则针对历版 PPT 的三个问题：版式同质卡片味重、AI 生成感不像研究者、信息密度两极（满页与空页并存）。它不是审美主张，而是一组**交付前可检查的约束**。`备课教训.md` 是问题记录，本文件是预防规则。定稿后，每个重设计页在进入 ppt-master 前先填本契约，验收时过三问。

## 一、全卷节奏规则（反同质）

连续说明页不得使用同一种叙事轮廓。`备课教训 #25`。

**轮廓词汇表**（每页必须归入其一，相邻两页不得相同）：

| 轮廓 | 适用 | 视觉特征 |
| --- | --- | --- |
| 主链 | 流程/八阶段/研究链路 | 单线节点 + 回退箭头 |
| 否定清单 | 非例/红线/禁止事项 | 主体为"不做"列表 + 一句正面对照 |
| 阶梯/门槛 | 工件成熟度/研究门/能力进阶 | 上升阶梯 + 回退箭头 |
| 对照 | 过宽vs最小权限/普通摘要vs阅读卡/两个配置 | 左右两域，必须有差异点高亮 |
| 路线图 | 16 课/四门/项目时间线 | 横轴时间 + 门槛标记 |
| 责任分工 | 个人vs同伴/Agentvs人 | 两栏分工，删一栏信息有损失 |
| 评分条 | 评分比例/预算分配 | 清单列项 + 按权重缩放的条形混合；清单负责名称，条形负责比例，不以等宽卡片替代 |
| 工件视图 | 研究仓库/diff/日志/证据表 | 真实或重绘的研究工件占主体 |

**轮换规则**：任意连续 3 页不得出现 2 页同轮廓；任意连续 5 页至少出现 3 种不同轮廓。等宽卡片矩阵不作为独立轮廓，只作为某一轮廓内部的次要元素。八阶段主链页固定为"主链"轮廓，不轮换为责任分工或阶梯。

## 二、每页设计契约（反 AI 生成感）

**关键页**在进入 ppt-master 前，先填四字段。填不出或字段打架的页，先改母稿再制图。**轻量页只过第五节验收三问，不填四字段契约。**

1. **论证角色**：这页在整堂课论证中干什么？（建立张力 / 展示真实工件 / 对照两种配置 / 给出路线 / 收束冲突）不得填"介绍概念"——介绍不是角色。
2. **主视觉对象**：占画布 ≥40% 的单一对象是什么？（一张 diff / 研究仓库树 / 一段失败日志 / 一张论文证据图 / 一张证据缺口表 / 一个实验规格卡）不得填"四个要点"——要点不是对象。
3. **叙事轮廓**：从第一节词汇表选一个，且与前一页不同。
4. **删除标准**：这页删到只剩什么仍成立？张力页删到"一个主张 + 一个主视觉 + 一句冲突"；说明页删到"一个主结论 + 可读清单"。

## 三、主视觉来源规则（反卡片味 / 补真实研究对象）

主视觉对象的来源由它在论证中的角色决定，`备课教训 #21`。**不得用等宽卡片矩阵替代以下任一**：

| 页角色 | 主视觉来源 | 禁止 |
| --- | --- | --- |
| 证据页（论文结论/数据/图） | 论文原图或准确裁图；题名、期刊与年份、图、本页结论同框 `#12 #17` | 用概念卡片复述结论 |
| 结构/机制页 | 矢量重绘；节点文字、连线、回路在投影尺寸检查 `#23` | 用图标拼贴替代结构 |
| 工件/操作页 | 真实研究工件截图或重绘：仓库树、Git diff、失败日志、证据表、任务契约 `#26` | 用"流程卡片"假装展示过操作 |
| 路线/评分页 | 按权重缩放的条形或横轴门槛 | 用等宽方块表示比例 |
| 概念/气氛页 | imagegen 概念图，须在 speaker notes 标"非证据" `#21` | 让生成图承载数值或论文证据 |

CS/AI 研究生锚点 `#26`：优先让这些对象进场——Git/diff、研究仓库树、失败日志、证据缺口表、实验规格卡、可复现检查清单。一个可判断的研究对象 > 三张概念卡片。

## 四、密度双轨（解决满页与空页并存）

母稿是讲义，不是屏显。`备课教训 #9`。

- **张力页 / 关键页**：低密度。一个主张 + 一个主视觉 + 一句冲突，其余删去或入 speaker notes。
- **说明页 / 路线页**：中密度。允许清单，但必须配第一节轮廓轮换，且每页只有一个主结论。
- **禁止**：把母稿段落原文搬上屏；用更多卡片填充空页；为"丰富"在无证据阅读任务的页硬塞图片 `#25`。

判断密度是否对：张力页看"删到只剩一个主视觉后是否仍成立"；说明页看"一屏能否读完且有一个主结论"。

## 五、验收三问（交付前过）

每页渲染后逐页过：

1. **删掉主视觉对象后，这页是否只剩卡片矩阵？** 是 → 重做。这页没有可判断的研究对象。
2. **和前一页叙事轮廓是否相同？** 是 → 换轮廓或合并。
3. **这页有没有一个真实或重绘的研究对象占 ≥40%？** 没有 → 补对象，或把它降为轻量说明页、把主视觉让给相邻页。

三问任一不过，不进正式课件。

## 六、关键页优先级（待选页阶段填写）

重设计不覆盖全 39 页。先选 3–5 个决定整堂课观感的关键页单独填契约、单独验收；其余轻量页保留模板化输出，靠轻重有别打破同质。

候选关键页（待教师圈定）：

- 开场张力页（P01–P06 区间，建立"AI 参与后谁负责"）
- 研究工作台页（P07 区间，展示可判断的研究工件）
- 八阶段主链页（P19–P26 区间，结构重绘 + 回退）
- 最小可审计交互页（P30–P35 区间，真实 diff/仓库/日志进场）
- 四门路线图页（P13/P15 区间，横轴门槛）

## 已裁定

1. 评分/路线页：用清单 + 按权重条形混合，不用纯条形，也不用等宽卡片。
2. 八阶段主链页：固定"主链"轮廓，不轮换为责任分工或阶梯。
3. 轻量页：只过第五节验收三问，不填四字段设计契约。
