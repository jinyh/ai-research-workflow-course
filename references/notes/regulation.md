中国教育主管部门及相关权威机构关于“AI for Research”（生成式AI用于科研/学术研究）的规范与建议，目前呈现**“分层治理 + 鼓励规范使用 + 严守学术诚信底线”**的格局。教育部本身尚未发布一部专门针对“AI for Research”的全国统一强制性法规，但通过专家委员会、委托学会、以及科技部等协同文件，形成了明确导向。高校则据此制定校级细则。以下按权威层级梳理（截至2026年7月）：

### 1. 教育部及相关直接指导文件（教育系统核心）
- **《规范研究生学位论文与实践成果中人工智能工具使用指南》**（2026年5月发布）  
  由**教育部学位管理与研究生教育司委托**中国学位与研究生教育学会研制发布。  
  **核心要点**：
  - 定义AI工具（生成式AI为主）。
  - 三大原则：**诚信使用、科学使用、安全使用**。
  - 学位申请人是第一责任人，导师负指导与审查责任。
  - **核心论点和创新贡献必须由申请人自主完成**，不得用AI代写或掩盖不端。
  - 必须出具“人工智能使用声明”（工具名称、版本、用途、环节、参数、验证过程等），答辩中可设置质询。
  - 涉密/敏感内容禁止使用AI处理。  
  这是目前针对研究生科研与学位论文最直接的全国性参考规范。

- **《教师生成式人工智能应用指引（第一版）》**（2025年11月，教育部教师队伍建设专家指导委员会正式发布）  
  我国首份专门针对教师的生成式AI应用规范。  
  明确**科研红线**：不得直接将AI生成内容作为自己的原创观点或研究成果；不得直接使用或仅简单修改后提交AI生成的论文、课题申报书、研究报告等；研究选题、核心设计、数据解读、论点撰写等必须由教师主导。允许语法检查、句式优化等辅助。

- 其他教育部相关：
  - 中小学层面有《中小学生成式人工智能使用指南（2025年版）》等，强调分学段限制，但对高等教育科研参考价值有限。
  - 教育部整体推动“AI+教育”改革，鼓励AI素养培养，但学术场景始终强调“人主智辅”和透明披露。

### 2. 科技部等科研主管部门文件（对高校科研人员同样适用）
- **《负责任研究行为规范指引（2023）》**（科技部监督司，2023年12月）  
  明确针对生成式AI：
  - 不得使用生成式AI**直接生成申报材料**。
  - 不得将生成式AI列为成果**共同完成人**。
  - 不得直接使用未经核实的AI生成参考文献。
  - 在研究实施、数据管理、成果署名与发表、文献引用等方面需依规合理使用，并披露。

### 3. 其他权威机构与高校实践（形成补充体系）
- **中国科学院**：《关于在科研活动中规范使用人工智能技术的诚信提醒》（2024年9月）——选题调研、申报材料、数据使用等场景的具体提醒，反对直接使用未经核实的AI内容。
- **中国社会科学院**：《人工智能辅助科研基本规范（试行）》（2026年7月）——明确“人主智辅、提质增效、如实披露、安全合规”四大原则，并列出10类严禁行为（如伪造数据、输入涉密信息、生成歪曲事实内容等）。
- 高校层面（教育部鼓励学校制定细则）：
  - 清华大学《人工智能教育应用指导原则》（2026）：强调主体责任、合规诚信、数据安全等。
  - 复旦大学本科毕业论文AI使用规定（“六个禁止”）。
  - 上海交大、南京大学等也有校级规范，普遍要求披露、禁止核心环节代写、禁止伪造数据。

### 总体原则总结（教育主管部门共识）
| 原则 | 具体要求 |
|------|----------|
| **人主智辅** | 人类主导核心创新、论证与责任，AI仅辅助 |
| **透明披露** | 必须声明工具、版本、使用环节、生成内容比例与验证过程 |
| **禁止事项** | 代写核心内容、伪造/篡改数据、直接生成申报材料、将AI列为作者、涉密数据处理 |
| **责任归属** | 使用者（学生/教师）对最终成果负全责，导师负指导审查责任 |
| **鼓励方向** | 文献整理、语法润色、非核心辅助分析等，在规范前提下探索 |
