# 材料契约

> `prepare-course-lesson` skill 内容门的通过条件。每课只有一套现行口径。

## 三份现行材料的职责边界

| 文件 | 使用者 | 内容边界 |
| --- | --- | --- |
| `lessons/lesson-NN/handout.md` | 学生 | 可脱离课堂独立阅读的正式讲义：概念与方法、完整案例、与个人项目直接相关的练习、术语和来源入口 |
| `lessons/lesson-NN/teaching-plan.md` | 教师 | 教学目标、90 分钟时间分配、课堂活动、演示脚本、形成性评价、课后复盘 |
| `lessons/lesson-NN/slides.md` | 课堂展示 | 逐页内容母稿：每页页面任务、内容母稿位置、证据角色、学生动作 |

## 内容门通过条件

1. 三份文件引用同一套课程规则、同一批案例和同一来源口径，无矛盾。
2. 讲义面向学生、可独立阅读，不按 PPT 页码或试讲话术组织。
3. 教师教案不替代学生讲义；教案负责"怎么教"，讲义负责"教什么"。
4. 课后学习只有在直接服务下一课、个人项目或研究门时设置，并明确核心/任选、预计时间、产出位置和是否提交。不固定设置"课后自测"，不为凑齐讲义体例增加任务。
5. 来源入口齐全：关键结论绑定可核验证据，AI 输出不构成证据（见 `AGENTS.md` 证据标准）。

## 不通过的常见信号

- 讲义段落原文搬上 PPT（母稿是讲义不是屏显）。
- 教案与讲义案例不一致。
- 逐页母稿引用了历史稿或试讲页为内容母版。
- 为"丰富"在无证据阅读任务的页硬塞图片。
- 残留旧口径（固定证据三角硬门槛、每周正式作业、默认小组提交）。
