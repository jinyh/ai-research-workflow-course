# 智能科研方法

面向 CS/AI 研究生的 32 学时研究生课程。课程主线是八阶段研究链路驱动的通用科研工作流，科研伦理与负责任 AI 贯穿全过程，ML 实验自动化作为项目实践中的强化模块。

## 课程定位

本课程不是 AI 工具展示课，而是"AI 增强的科研方法与实践"课程。学生需要围绕一个真实或半真实的研究问题，完成从文献理解、问题定义、第一性原理推导、机制假设、证据整理、研究判断、原型验证到回写与表达的小型科研闭环。

课程引入结构化研究方法论：八阶段研究链路、研究门、证据分级与多源核验、研究工件（标准格式和轻量状态追踪）。学生掌握的是有门的科研工作流，而非松散的"做了什么就写什么"模式。

建议课程比例：

- 通用科研工作流：70%-80%
- ML 实验自动化：20%-30%

## 适用对象

- 计算机、人工智能、软件工程、数据科学相关方向研究生
- 已具备基本 Python 编程能力
- 已具备基本机器学习概念和论文阅读能力
- 已具备 Git 基本操作和命令行环境使用能力

## 学习目标

完成课程后，学生应能：

1. 使用八阶段研究链路组织科研工作流，而非松散地"做了什么就写什么"。
2. 使用 AI 辅助完成系统化文献检索、阅读、归纳和研究空白识别，并标注证据角色。
3. 将宽泛兴趣收敛为可验证的研究问题、写出非例和可证伪命题，从第一性原理推导必要条件、关键约束和可检验前提。
4. 组织证据地图，区分主证据、补充证据和证据空白，进行证据充分性检查。
5. 记录研究判断（取舍理由、适用边界），设计可复现的实验规格。
6. 在 ML 实验中使用自动化方法支持实验迭代、超参探索和失败分析，产出评价报告。
7. 写出结构清晰、证据链完整、结论可追溯到证据和决策的研究计划和论文式短文。
8. 识别 AI 输出中的幻觉、偏差、不可验证结论和学术规范风险。
9. 在数据、模型、代码、署名、引用、隐私和双重用途等环节进行科研伦理判断。
10. 通过四个研究门（问题门、判断门、验证门、论证门），完成有门的科研闭环。

## 课程产出

每位学生或每个小组提交：

- 问题定义：结构性问题、范围、非例和可证伪命题
- 第一性原理推导：必要条件、关键约束和可检验前提
- 研究计划：问题、相关工作、假设、实验设计、指标、风险
- 证据地图：主证据、补充证据、空白标注
- 研究判断记录：关键取舍、适用边界、待验证状态
- 实验规格：假设对应、变量、步骤、度量
- 原型仓库：代码、运行说明、实验记录、结果表格或图
- 评价报告：实验结果与原假设关系、失败与限制
- AI 使用记录：关键提示词、上下文来源、模型/工具、权限边界、人工校验方式、失败案例
- 科研伦理与合规说明：数据来源、隐私风险、许可、署名、AI 使用披露和潜在误用
- 复盘报告：AI 有效之处、误导之处、不能自动化的科研判断、八阶段链路反思
- 工件状态追踪表：关键工件的状态和追踪关系
